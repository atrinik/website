# Security policy

Report vulnerabilities privately through GitHub Security Advisories for
`atrinik/website`. Do not include credentials, private account data, or exploit
details in a public issue.

The supported site is static output from `main`. It intentionally accepts no
user input and uses no cookies, analytics, browser scripts, third-party embeds,
Pages Functions, bindings, or secrets. Treat imported metadata, Markdown,
URLs, SVG, and media as untrusted and validate them before publication.
